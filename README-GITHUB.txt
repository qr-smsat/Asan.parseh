مدیریت شارژ آسان مجتمع - پارسه | V1.27

این پروژه برای ساخت APK با GitHub Actions آماده شده است و به AndroidIDE نیاز ندارد.

روش استفاده:
1) در GitHub یک Repository جدید بسازید.
2) تمام فایل‌های این پوشه را در ریشه Repository قرار دهید؛ پوشه app و فایل‌های build.gradle و settings.gradle باید در ریشه باشند.
3) Commit را انجام دهید.
4) در GitHub وارد تب Actions شوید.
5) Workflow با نام «Build Parseh Charge APK» را انتخاب کنید.
6) روی Run workflow بزنید.
7) پس از پایان موفق Build، وارد همان اجرای Workflow شوید و از بخش Artifacts فایل «ParsehCharge-V1.27-debug» را دانلود کنید.
8) ZIP دانلودشده را باز کنید و app-debug.apk را روی گوشی نصب کنید.

قابلیت‌های APK در V1.27:
- انتخاب پوشه بکاپ با انتخاب‌گر واقعی اندروید
- ذخیره مستقیم بکاپ JSON در پوشه انتخاب‌شده
- انتخاب فایل بکاپ با انتخاب‌گر واقعی اندروید
- بازگردانی بکاپ از فایل انتخاب‌شده
- در صورت ناموفق بودن ذخیره در پوشه، انتخاب محل ذخیره فایل به‌صورت جایگزین
- پشتیبانی از انتخاب فایل برای inputهای فایل HTML از طریق WebChromeClient

نکته: این پروژه برای Build خودکار از Gradle 8.10.2 و Java 17 استفاده می‌کند.
